Parent / holding structure for autonomous and high-leverage software systems.

## Current Portfolio

| System | Repo | Status | Economic Stage |
|--------|------|--------|----------------|
| **ActionForge** | [actionforge](https://github.com/azca9118-lang/actionforge) | MVP hardened | Commercial readiness partial — core extraction live, auth/payments next |

## Purpose

Apex exists to:

1. Own and orchestrate high-ROI autonomous products
2. Provide shared infrastructure, credentials governance, and economic tracking when scale justifies it
3. Keep individual product repositories focused and independently deployable

## Principles

- Verified capability over impressive claims
- Security and authorization boundaries first
- Economic reality gates (capability → opportunity → readiness → revenue-generating)
- Minimal necessary complexity

## Next

- Continue hardening ActionForge toward first verified revenue
- Only add shared services (auth, billing, observability) when at least one product demonstrates repeatable demand
